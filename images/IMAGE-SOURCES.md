## Technical Notes
- All downloaded photographs have been optimized and resized to standard web dimensions (800x533 for cards, 1200x500/600 for banners, 300x300 for avatars).
- Average file sizes range from 10 KB to 200 KB, ensuring high visual fidelity without slow load times or bloated repository storage.
- All references in HTML and CSS use strictly relative local filepaths (e.g. `images/food/classic-burger.jpg` or `../images/food/classic-burger.jpg`).
- Zero remote or external image URLs are embedded in HTML or CSS.
